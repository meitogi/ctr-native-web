A stand-in for the game page : the canvas below is presented 30 times a second like the game's (one present() per frame), a tone stands in for SDL's ScriptProcessorNode, and the guests' pads are read back like the game's input update. Serve the repository root, run a relay, open web/share/demo/index.html#relay=ws://localhost:8787&rk=…, press Share, open the guest link in another tab.
